# Milestone v1.6: Pipeline-Analytics

**Status:** SHIPPED 2026-01-17
**Phases:** 23-24
**Total Plans:** 2

## Overview

Reports zu einem fokussierten Pipeline-Dashboard konsolidieren, Dashboard entschlacken. 3-Tab Reports durch ein einheitliches PipelineDashboard ersetzt, ThroughputChart für Zeitreihen hinzugefügt, Problem-KPI vom Dashboard entfernt (jetzt in Reports SnapshotKPIs).

## Phases

### Phase 23: Reports neu

**Goal**: Pipeline Analytics Dashboard erstellen mit Funnel, Snapshot-KPIs und Zeitraum-KPIs
**Depends on**: Phase 22
**Plans**: 1 plan

Plans:
- [x] 23-01: Pipeline Analytics Dashboard

**Details:**
- Created Pipeline Analytics API (`/api/reports/pipeline`) with throughput, snapshot, and period KPIs
- Built PipelineFunnel component showing 4-stage horizontal funnel
- Created SnapshotKPIs for current state metrics (aktive Aufträge, Problem-Aufträge, ältester Auftrag, morgen fällig)
- Created PipelineKPIs for period metrics with comparison badges
- Consolidated Reports page replacing 3-tab structure with single PipelineDashboard

### Phase 24: Reports Zeitreihen + Dashboard

**Goal**: ThroughputChart hinzufügen, Dashboard streamlinen
**Depends on**: Phase 23
**Plans**: 1 plan

Plans:
- [x] 24-01: Zeitreihen Dashboard

**Details:**
- Created `/api/reports/timeseries` endpoint for daily eingang/versendet counts
- Built ThroughputChart component with dual-line recharts visualization
- Replaced VolumeChart with ThroughputChart in PipelineDashboard
- Removed Problem-KPI from main Dashboard (now exclusive to Reports SnapshotKPIs)
- Streamlined Dashboard from 5 to 4 KPI cards

- Consolidated 3-tab Reports into single PipelineDashboard for clearer UX
