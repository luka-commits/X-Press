# Milestone v1.2: Versand Pro

**Status:** ✅ SHIPPED 2026-01-16
**Phases:** 13-14
**Total Plans:** 2

## Overview

Verbesserte Versand-Seite mit Google Maps, interaktiver Karte und Inline-KPIs

## Design-Entscheidungen (2026-01-16)

Nach Diskussion über UI-Optionen:

| Entscheidung | Begründung |
|--------------|------------|
| ❌ Kein Split-View | Karte nimmt Platz weg, 90% der Zeit nicht gebraucht |
| ✅ Karte als Toggle | Opt-in, volle Breite wenn aktiv, wie v1.1 aber besser |
| ✅ Liste↔Karte Interaktion | Macht Karte nützlich ohne permanent Platz zu brauchen |
| ✅ Inline-KPIs | Schneller Überblick, Reporting-Tab kommt separat |
| 🔮 Routenplanung später | Multi-Select/Route erst wenn Use-Case validiert |

## User-Perspektiven

**Geschäftsführer:**
- Schneller Überblick: "Was muss heute raus?"
- KPIs auf einen Blick
- Karte bei Bedarf für geografische Verteilung

**Versand-Team:**
- Liste durcharbeiten, Status ändern
- Karte optional für "wo muss ich hin?"
- Routenplanung → v1.3+ wenn validiert

## Phase Details

### Phase 13: Google Maps Migration

**Goal**: Leaflet durch Google Maps ersetzen, API-Key konfigurieren, Clustering beibehalten

**Scope:**
- Google Maps JavaScript API einrichten
- `@react-google-maps/api` oder `@vis.gl/react-google-maps` evaluieren
- DeliveryMap Komponente neu implementieren
- Marker-Clustering mit Google Maps
- Leaflet Dependencies entfernen

**Nicht in Scope:**
- Interaktion mit Liste (Phase 14)
- KPIs (Phase 15)

### Phase 14: Desktop Layout + KPIs + Karte-Liste Interaktion

**Goal**: Komplette Versand-Seite mit KPIs, Desktop Split-View und bidirektionaler Interaktion

**KPIs (für Geschäftsführer):**
- Kompakte KPI-Leiste: "12 Offen · 5 Versandbereit · 3 Versendet · 2 Überfällig"
- Sofortiger Überblick ohne Scrollen
- Überfällig in rot wenn > 0

**Layout:**
- Desktop (≥768px): Split-View mit Liste links, Karte rechts (immer sichtbar)
- Mobile (<768px): Toggle-basierte Karte (bestehendes Verhalten)

**Interaktion:**
- Klick auf Order-Card → Karte zoomt zu diesem Punkt, Marker highlighted
- Klick auf Marker → Order-Card scrollt in View, wird hervorgehoben
- InfoWindow/Popup bei Marker-Klick mit Order-Details
- Smooth scroll/animation für bessere UX

**Technisch:**
- VersandKPIs Komponente (berechnet Counts aus Orders-Array)
- Responsive Grid mit `md:` Breakpoint
- Shared state für selectedOrder zwischen Liste und Karte
- Map-Instanz Zugriff für programmatisches Zoomen

## Milestone Summary

**Key Decisions:**

- Google Maps API chosen over Leaflet for better UX and future route planning capability
- Desktop Split-View layout for ≥768px, toggle-based for mobile
- Inline KPIs integrated directly into Phase 14 (originally Phase 15)
- Bidirectional list-map interaction for practical usability

**Issues Resolved:**

- Leaflet rendering issues resolved by migration to Google Maps
- KPI visibility improved with inline display instead of separate tab

**Issues Deferred:**

- Multi-select for route planning (v1.3+ when use-case validated)
- Route visualization and export (v1.3+)
- Dashboard KPI integration (separate Reporting tab)

**Technical Debt:**

- None incurred
