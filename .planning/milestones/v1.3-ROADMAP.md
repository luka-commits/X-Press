# Milestone v1.3: Routenplanung

**Status:** ✅ SHIPPED 2026-01-16
**Phases:** 15-17
**Total Plans:** 3

## Overview

Routenplanung für Versand-Team mit Optimierung und Google Maps Navigation Export.

## Design-Entscheidungen (2026-01-16)

| Entscheidung | Begründung |
|--------------|------------|
| ✅ Route Mode Toggle | Klare Trennung zwischen Übersicht und Routenplanung |
| ✅ Checkbox-Selection | Einfache Multi-Select UX für Auftragsauswahl |
| ✅ Google Routes API | Optimale Reihenfolge berechnen mit echten Fahrzeiten |
| ✅ Link-Export statt App | Google Maps Deep Link funktioniert auf allen Geräten |
| ❌ Kein Fahrer-Management | Link-Export reicht für aktuellen Workflow |

## User-Perspektiven

**Versand-Team:**
- Aufträge für Route auswählen
- Optimale Reihenfolge berechnen lassen
- Google Maps Link kopieren → auf Handy öffnen → losfahren

**Geschäftsführer:**
- Route-Stats auf einen Blick (Anzahl Stops, Gesamtdauer, Distanz)
- Sehen welche Aufträge in Route sind

## Phase Details

### Phase 15: Routenplanung-Basis

**Goal**: Modus-Toggle, Auftragsauswahl, Route auf Karte visualisieren

**Scope:**
- Route Mode Toggle Button in Versand-Seite
- Checkbox-basierte Multi-Selection für Orders
- Route-Linie auf Karte (Luftlinie zwischen Punkten)
- Route-Stats Leiste (Anzahl Stops)
- Clear-Selection Button

### Phase 16: Routenoptimierung

**Goal**: Google Routes API Integration, optimale Reihenfolge berechnen

**Scope:**
- Google Routes API Integration
- "Optimieren" Button
- Optimale Reihenfolge berechnen (TSP)
- Road-following Polyline statt Luftlinie
- Fahrtzeit und Distanz in Stats

**Technisch:**
- `/api/routes/optimize` Endpoint
- Google Routes API mit `optimizeWaypointOrder: true`
- Encoded Polyline dekodieren für Kartenansicht

### Phase 17: Export & Fahrer

**Goal**: Navigation-Export (Deep Links)

**Scope:**
- "Link kopieren" Button
- Google Maps Navigation URL generieren
- Waypoints in optimierter Reihenfolge
- Copy-to-clipboard mit Feedback

**Nicht implementiert (deferred):**
- Fahrer-Zuweisung
- Fahrer-Stammdaten

## Zukünftige Features (nicht v1.3)

Diese wurden bewusst ausgeklammert:

- **Fahrer-Management** - Stammdaten, Zuweisung (bei Bedarf v1.4+)
- **Routen-Persistenz** - Geplante Routen speichern
- **Multi-Route** - Mehrere Routen gleichzeitig planen
- **Zeitfenster** - Lieferzeit-Constraints bei Optimierung

## Milestone Summary

**Key Decisions:**

- Google Routes API for real road-based optimization (not just straight lines)
- Simple link export over complex app integration
- Phase 18 (Fahrer-Management) removed - current workflow doesn't need it

**Issues Resolved:**

- Route planning requested since v1.2 - now delivered
- Manual route ordering eliminated with optimization API

**Issues Deferred:**

- Driver assignment (no current use case)
- Route persistence (copy link is enough for now)

**Technical Debt:**

- None incurred
