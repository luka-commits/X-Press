# Phase 17: Export & Fahrer - Context

**Gathered:** 2026-01-16
**Status:** Ready for planning

<vision>
## How This Should Work

Admin assigns routes to drivers from the Versand page. Once a route is optimized and assigned, the admin clicks "Copy link" to get a shareable navigation link. They paste this into WhatsApp and send it to the driver.

Driver receives the WhatsApp message, taps the link, and Google Maps opens directly with the full optimized route — ready to start navigating. Zero friction, no login required.

Drivers can also log in to XOS Versand page to see their assigned orders and export from there if needed.

</vision>

<essential>
## What Must Be Nailed

- **One-tap to navigation** — Driver clicks link, Google Maps opens with the route, done
- **Shareable link that works** — Link opens Google Maps directly with all stops in the optimized order

</essential>

<specifics>
## Specific Ideas

- Google Maps only (that's what everyone uses)
- "Copy link" button for admin — manual paste into WhatsApp
- Link opens Google Maps directly, not an intermediate XOS page
- No automated notification system needed — manual WhatsApp is fine

</specifics>

<notes>
## Additional Context

The priority is the export experience, not the assignment workflow. Getting from "route assigned" to "driver navigating" with minimal friction is what matters most.

Driver assignment is part of this phase but secondary — the core value is the seamless export to Google Maps.

</notes>
