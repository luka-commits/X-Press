  <name>Task 1: Create PATCH /api/orders/[id]/status endpoint</name>
  <files>src/app/api/orders/[id]/status/route.ts</files>
  <action>
Create new route file following existing patterns from `/api/orders/[id]/route.ts`:

1. Import NextRequest, NextResponse from 'next/server'
2. Import prisma from '@/lib/prisma'
3. Import IstStatus from '@prisma/client' for validation

PATCH handler:
- Parse request body: `{ istStatus: string, statusKommentar?: string }`
- Validate istStatus is valid IstStatus enum value (in_produktion, fertig, problem)
- Return 400 if invalid status value with descriptive German error message
- Verify order exists (return 404 if not found with German error message)
- Update Auftrag: set istStatus, statusKommentar (null if not provided), statusUpdatedAt to new Date()
- Return updated order with 200 status

Error handling following codebase conventions:
- Try/catch with console.error logging
- Return JSON error responses with German messages
- Status codes: 200 success, 400 bad request, 404 not found, 500 internal error

Validation approach:
- Check `Object.values(IstStatus).includes(istStatus)` to validate enum
- This ensures only valid values from Prisma schema are accepted
  </action>

- curl PATCH with invalid status returns 400
- curl PATCH with non-existent order returns 404
  </verify>
