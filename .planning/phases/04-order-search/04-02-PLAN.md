<task type="auto">
  <name>Task 1: Create OrderSearch component</name>
  <files>src/components/status/OrderSearch.tsx</files>
  <action>
Create mobile-optimized search component:

1. Input field with:
   - placeholder "Auftragsnummer oder Kunde..."
   - Search icon (lucide-react)
   - Large touch target (min-h-12 for 48px)
   - Auto-focus on mount

2. Debounced search (300ms) using native setTimeout/clearTimeout:
   - Track search term in state
   - Only fetch when term >= 2 characters
   - Clear results when term < 2 chars

3. Results dropdown:
   - Absolute positioned below input
   - Show up to 10 results
   - Each result shows: auftragsnummer (bold), kunde firma, produkttyp
   - Large touch targets (min-h-14 for 56px per item)
   - Shadow and white background

4. Loading state:
   - Show spinner while fetching
   - Use Loader2 from lucide-react with animate-spin

5. Props:
   - onSelect(order): callback when user taps a result
   - className: optional additional styles

Use tailwind classes matching existing components (bg-white, border-ghl-border, text-ghl-text).
Do NOT install any external debounce library - use native setTimeout.
  </action>
  <verify>Component renders without errors, input accepts text</verify>
