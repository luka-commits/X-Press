  <action>
Create POST endpoint that calls Google Routes API with waypoint optimization:

1. Create `src/types/route.ts` with types:
   - `OptimizeRouteRequest`: origin, destination, waypoints (array with lat, lng, orderId)
   - `OptimizeRouteResponse`: optimizedOrderIds, duration, distanceMeters, encodedPolyline

2. Create `src/app/api/routes/optimize/route.ts`:
   - Accept POST with origin, destination, waypoints
   - Call `https://routes.googleapis.com/directions/v2:computeRoutes`
   - Use `process.env.GOOGLE_ROUTES_API_KEY` (NOT the public key)
   - Set `optimizeWaypointOrder: true`
   - Use field mask: `routes.duration,routes.distanceMeters,routes.polyline.encodedPolyline,routes.optimizedIntermediateWaypointIndex`
   - Map `optimizedIntermediateWaypointIndex` back to orderIds
   - Return optimizedOrderIds, duration, distanceMeters, encodedPolyline

Use X-Press location as default origin/destination: `{ lat: 52.4046, lng: 13.3718 }` (Nunsdorfer Ring 13, Berlin)

Error handling:
- Return 500 if GOOGLE_ROUTES_API_KEY not set
- Return error details from Routes API if request fails
- Log errors server-side for debugging
  </action>
