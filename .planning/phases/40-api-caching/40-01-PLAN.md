  <name>Task 1: Add Cache-Control to Dashboard KPI route</name>
  <files>src/app/api/dashboard/kpi-orders/route.ts</files>
  <action>
    1. Remove `export const dynamic = 'force-dynamic'` line
    2. Add Cache-Control header to successful responses:
       `'Cache-Control': 'public, s-maxage=60, stale-while-revalidate=300'`
       (60s CDN cache, serve stale up to 5min while revalidating)

    Dashboard auto-refreshes every 5 minutes anyway.
  </action>
  <verify>

    Response should include: Cache-Control: public, s-maxage=60, stale-while-revalidate=300
  </verify>

<task type="auto">
  <name>Task 2: Add Cache-Control to Reports routes</name>
  <files>
    src/app/api/reports/analytics/route.ts,

    src/app/api/reports/timeseries/route.ts,
    src/app/api/reports/versand/route.ts
  </files>
  <action>
    For each of the 7 reports routes:

    1. Remove `export const dynamic = 'force-dynamic'` line
    2. Add Cache-Control header to successful responses:
       `'Cache-Control': 'public, s-maxage=300, stale-while-revalidate=1800'`
       (5min CDN cache, serve stale up to 30min while revalidating)
    3. Add `'Cache-Control': 'no-store'` to all error responses

    Reports show historical data with date range filters - even more cache-tolerant
    than dashboard KPIs. Users selecting past date ranges get fully cacheable responses.

    Pattern for success response:
    ```typescript
    return NextResponse.json(data, {
      headers: {
        'Cache-Control': 'public, s-maxage=300, stale-while-revalidate=1800',
      },
    });
    ```

    Pattern for error response:
    ```typescript
    return NextResponse.json(
      { error: '...' },
      { status: 500, headers: { 'Cache-Control': 'no-store' } }
    );
    ```
  </action>
  <verify>
    curl -I "http://localhost:3000/api/reports/pipeline?from=2026-01-01&to=2026-01-17"
    Response should include: Cache-Control: public, s-maxage=300, stale-while-revalidate=1800
  </verify>
  <done>All 7 reports routes return Cache-Control headers on success, no-store on errors</done>
</task>
