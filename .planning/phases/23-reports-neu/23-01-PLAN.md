<task type="auto">
  <name>Task 1: Create Pipeline Analytics API endpoint</name>
  <files>src/app/api/reports/pipeline/route.ts</files>
  <action>
Create GET endpoint `/api/reports/pipeline` that accepts `from` and `to` query params (ISO date strings).

Return shape:
```typescript
{
  funnel: {
    eingang: { count: number, prevCount: number, changePercent: number },
    produktion: { count: number, prevCount: number, changePercent: number },
    versandbereit: { count: number, prevCount: number, changePercent: number },
    versendet: { count: number, prevCount: number, changePercent: number },
  },
  kpis: {
    totalActive: number,
    problemOrders: number,
    avgDaysToShip: number | null,
    onTimePercent: number,
  },
  prevPeriod: {
    totalActive: number,
    problemOrders: number,
    avgDaysToShip: number | null,
    onTimePercent: number,
  }
}
```

Logic:
- **Funnel counts** for current period based on statusUpdatedAt (when order reached that stage):
  - eingang: orders created (use createdAt) in period
  - produktion: orders with istStatus changed to 'in_produktion' in period (statusUpdatedAt)
  - versandbereit: orders with istStatus='fertig' or versandStatus='bereit' in period
  - versendet: orders with versandStatus='versendet' (versandUpdatedAt) in period
- **Previous period**: Calculate same metrics for period of equal length before from date
- **changePercent**: ((current - prev) / prev) * 100, handle division by zero

Use Supabase REST queries following existing patterns in dashboard-queries.ts.
  </action>
  <verify>curl http://localhost:3000/api/reports/pipeline?from=2026-01-01&to=2026-01-17 returns JSON with funnel and kpis data</verify>
  <done>API returns pipeline funnel counts, KPIs, and period comparison data</done>
</task>
