  <name>Task 1: Create Pipeline Analytics API endpoint</name>
  <files>src/app/api/reports/pipeline/route.ts</files>
  <action>
Create GET endpoint `/api/reports/pipeline` that accepts `from` and `to` query params (ISO date strings).

Return shape:
```typescript
{
  // Throughput: How many orders MOVED through each stage in the period
  throughput: {
    eingang: { count: number, prevCount: number, changePercent: number },
    produktion: { count: number, prevCount: number, changePercent: number },
    versandbereit: { count: number, prevCount: number, changePercent: number },
    versendet: { count: number, prevCount: number, changePercent: number },
  },
  // Snapshot: Current state (independent of date range)
  snapshot: {
    aktiveAuftraege: number,      // Orders not yet shipped
    problemAuftraege: number,     // Orders with hatProblem=true
    aeltesterAuftrag: number | null, // Days since oldest unshipped order created
    morgenFaellig: number,        // Orders due tomorrow
  },
  // Period KPIs: Historical metrics for the selected period
  periodKpis: {
    avgDaysToShip: number | null,
    onTimePercent: number,
    totalShipped: number,
  },
  prevPeriodKpis: {
    avgDaysToShip: number | null,
    onTimePercent: number,
    totalShipped: number,
  }
}
```

Logic:
- **Throughput** (Durchfluss im Zeitraum):
  - eingang: orders with createdAt in period
  - produktion: orders with statusUpdatedAt in period AND istStatus changed to 'in_produktion'
  - versandbereit: orders with statusUpdatedAt in period AND (istStatus='fertig' OR versandStatus='bereit')
  - versendet: orders with versandUpdatedAt in period
- **Snapshot** (aktueller Stand - ignores date range):
  - aktiveAuftraege: count where versandStatus != 'versendet'
  - problemAuftraege: count where hatProblem = true
  - aeltesterAuftrag: DATEDIFF(now, MIN(createdAt)) where versandStatus != 'versendet'
  - morgenFaellig: count where lieferdatum = tomorrow AND versandStatus != 'versendet'
- **Period KPIs** (historisch, Zeitraum-abhängig):
  - avgDaysToShip: AVG(versandUpdatedAt - createdAt) for shipped orders in period
  - onTimePercent: shipped on/before lieferdatum / total shipped * 100
  - totalShipped: count shipped in period
- **Previous period**: Calculate same metrics for equal length period before `from`
- **changePercent**: ((current - prev) / prev) * 100, handle division by zero

Use Supabase REST queries following existing patterns in dashboard-queries.ts.
