<task type="auto">
  <name>Task 1: Install bundle analyzer and run analysis</name>
  <files>next.config.mjs, package.json</files>
  <action>
  1. Install @next/bundle-analyzer: `npm install -D @next/bundle-analyzer`
  2. Update next.config.mjs to conditionally enable bundle analyzer:
     ```js
     import withBundleAnalyzer from '@next/bundle-analyzer';
     const bundleAnalyzer = withBundleAnalyzer({ enabled: process.env.ANALYZE === 'true' });
     export default bundleAnalyzer(nextConfig);
     ```
  3. Run `ANALYZE=true npm run build` to generate bundle report
  4. Capture key metrics:
     - Total bundle size (First Load JS)
     - Per-route bundle sizes
     - Largest dependencies (identify candidates for optimization)
     - Shared chunks size
  5. Take screenshots or note the visualization results
  </action>
  <verify>Build completes with ANALYZE=true and generates .next/analyze/ reports</verify>
  <done>Bundle analysis complete with size breakdown documented</done>
</task>

<task type="auto">
  <name>Task 2: Run Lighthouse audits on all routes</name>
  <files>.planning/phases/35-performance-audit/AUDIT-RESULTS.md</files>
  <action>
  1. Start production build: `npm run build && npm run start`
  2. Run Lighthouse CLI for each route (install if needed: `npm install -g lighthouse`):
     ```bash
     lighthouse http://localhost:3000 --output=json --output-path=./lighthouse-dashboard.json
     lighthouse http://localhost:3000/status --output=json --output-path=./lighthouse-status.json
     lighthouse http://localhost:3000/versand --output=json --output-path=./lighthouse-versand.json
     lighthouse http://localhost:3000/auftraege --output=json --output-path=./lighthouse-auftraege.json
     lighthouse http://localhost:3000/reports --output=json --output-path=./lighthouse-reports.json
     ```
  3. For each route, record in AUDIT-RESULTS.md:
     - Performance score (0-100)
     - Accessibility score
     - Best Practices score
     - SEO score
     - Core Web Vitals: LCP, FID/INP, CLS
     - First Contentful Paint (FCP)
     - Time to Interactive (TTI)
     - Total Blocking Time (TBT)
  4. Note any warnings or failed audits
  </action>
  <verify>Lighthouse JSON reports exist for all 5 routes</verify>
  <done>All routes audited with scores documented in AUDIT-RESULTS.md</done>
</task>
