Add to schema.prisma:

1. Create IstStatus enum ABOVE the Auftrag model:
   - in_produktion - Currently being worked on
   - fertig - Completed
   - problem - Has issues that need attention

2. Add three new fields to Auftrag model (after the existing `status` field):
   - istStatus: IstStatus? - Optional, null means no status reported yet from shopfloor
   - statusKommentar: String? - Optional comment from worker
   - statusUpdatedAt: DateTime? - When status was last changed

Note: The existing `status` field (String, default "aktiv") tracks order lifecycle. The new `istStatus` tracks actual production state from the shopfloor. These are different concerns.

Do NOT modify any existing fields or relationships.
