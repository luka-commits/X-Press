  <name>Task 2: Rewrite DeliveryMap with Google Maps</name>
  <files>src/components/map/DeliveryMap.tsx, src/components/map/MapContainer.tsx</files>
  <action>
    Rewrite DeliveryMap.tsx to use Google Maps:

    1. **Replace imports:**
       - Remove all Leaflet imports and CSS
       - Import from `@react-google-maps/api`: GoogleMap, useLoadScript, MarkerF, InfoWindowF
       - Import MarkerClusterer from `@googlemaps/markerclusterer`

    2. **Component structure:**
       - Use `useLoadScript` hook to load Google Maps API with API key from env
       - Show loading state while script loads
       - Show error state if API key missing or invalid
       - Berlin center: { lat: 52.52, lng: 13.405 }
       - Default zoom: 10

    3. **Marker clustering:**
       - Use `@googlemaps/markerclusterer` for clustering
       - Create markers programmatically via google.maps.Marker
       - Initialize clusterer with map instance via onLoad callback

    4. **InfoWindow (popup):**
       - Track selected marker in state
       - Show InfoWindow on marker click with order details
       - Same content as Leaflet popup: auftragsnummer, kunde, PLZ/Ort

    5. **MapContainer.tsx:**
       - Simplify: Google Maps handles its own loading, no dynamic import needed
       - Keep DeliveryMapProps interface for type safety
       - Export DeliveryMap directly (or keep thin wrapper for loading state)

    6. **Styling:**
       - Keep same dimensions: h-[400px] w-full rounded-lg
       - Use mapContainerClassName prop for Tailwind classes

    Key differences from Leaflet:
    - No CSS imports needed (Google loads its own)
    - No dynamic import needed (useLoadScript handles async loading)
    - Markers created programmatically, not JSX children
    - InfoWindow instead of Popup
  </action>
