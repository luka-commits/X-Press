<task type="auto">
  <name>Task 2: Create completed orders API endpoint</name>
  <files>src/app/api/reports/completed/route.ts</files>
  <action>
Create GET endpoint for completed orders at /api/reports/completed.

Query logic:
- Fetch Auftrag where: istStatus = 'fertig' OR versandStatus = 'versendet'
- Include related Kunde data (name, firma)
- Sort by completion date (statusUpdatedAt or versandUpdatedAt, whichever is more recent) descending
- Support pagination: page (default 1), pageSize (default 20)

Response shape:
```typescript
{
  orders: Array<{
    auftragsnummer: string;
    kunde: { name: string | null; firma: string | null } | null;
    produkttyp: string | null;
    liefertermin: string | null;
    istStatus: string | null;
    versandStatus: string | null;
    completedAt: string; // statusUpdatedAt or versandUpdatedAt
  }>;
  total: number;
  page: number;
  totalPages: number;
}
```

Use Supabase client (following dashboard-queries.ts pattern) with:
- .or() filter for the OR condition
- .order() for sorting by most recent completion date
- .range() for pagination

Handle errors: Return 500 with JSON error message on failure.
  </action>

  </verify>
