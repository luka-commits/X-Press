1. Create GET endpoint at src/app/api/reports/analytics/route.ts:
   - Import NextResponse, createClient from @/lib/supabase
   - Query params: from (ISO date string), to (ISO date string)
   - Validate both params present, return 400 if missing
   - Parse dates using new Date(from), new Date(to)

2. Use Supabase REST API (consistent with existing reports pattern):
   - Query orders table with filters:
     - status_updated_at >= from AND status_updated_at <= to
     - OR ist_status = 'fertig' OR versand_status = 'versendet' (completed orders)
   - Select: id, status_updated_at, liefertermin

3. Group results by day in TypeScript (Supabase REST doesn't support GROUP BY):
   - Create Map<string, number> for date -> count
   - Format each status_updated_at to 'yyyy-MM-dd' using date-fns
   - Increment count for each date
   - Convert to array: [{ date: 'yyyy-MM-dd', count: number }]
   - Sort by date ascending

4. Return JSON response:
   ```json
   {
     "data": [
       { "date": "2026-01-10", "count": 15 },
       { "date": "2026-01-11", "count": 23 }
     ],
     "from": "2026-01-10",
     "to": "2026-01-16"
   }
   ```

5. Error handling:
   - 400 for missing/invalid date params
   - 500 for database errors with error message

AVOID: Don't use Prisma raw SQL - use Supabase REST API for consistency with CompletedOrdersTable pattern.
