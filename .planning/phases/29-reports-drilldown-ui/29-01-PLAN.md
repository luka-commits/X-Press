  <action>
Create a dialog component for displaying orders from Reports KPI drilldowns.

Follow the KPIOrdersDialog pattern from dashboard:
- Props: kpiType ('problem' | 'oldest' | 'tomorrow' | 'stage'), title, isOpen, onOpenChange, stage? (optional for type='stage')
- Fetch from `/api/reports/kpi-orders?type={kpiType}&stage={stage}` when isOpen becomes true
- Display orders in a table with columns: Auftrag (link), Kunde, Produkttyp, Liefertermin, Tage übrig
- Handle loading, error, and empty states with German text
- Use shadcn Dialog component (already installed from phase 25)
- Color-code "Tage übrig" badge: 0 = red, 1 = yellow, else green (matching dashboard pattern)

The response from API:
```typescript
interface KPIOrdersResponse {
  type: 'problem' | 'oldest' | 'tomorrow' | 'stage';
  orders: KPIOrderItem[];
  count: number;
  date: string;
  stage?: StageType;
}

interface KPIOrderItem {
  auftragsnummer: string;
  kunde: string;
  produkttyp: string | null;
  liefertermin: string | null;
  tageUebrig: number;
}
```
