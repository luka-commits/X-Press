<task type="auto">
  <name>Task 1: Make FunnelChart bars clickable</name>
  <files>src/components/reports/FunnelChart.tsx</files>
  <action>
Make each funnel bar clickable to show orders in that stage.

1. Add onStageClick callback prop:
   ```typescript
   interface FunnelChartProps {
     data: FunnelStage[];
     onStageClick?: (stage: string) => void;
   }
   ```

2. Map stage names to API stage values. The FunnelStage has German names, API expects lowercase identifiers:
   - "Offen" → "offen"
   - "In Produktion" → "in_produktion"
   - "Fertig" → "fertig"
   - "Versandbereit" → "versandbereit"
   - "Versendet" → "versendet"
   - "Problem" → "problem"

   Add a helper function:
   ```typescript
   function getStageKey(name: string): string {
     const mapping: Record<string, string> = {
       'Offen': 'offen',
       'In Produktion': 'in_produktion',
       'Fertig': 'fertig',
       'Versandbereit': 'versandbereit',
       'Versendet': 'versendet',
       'Problem': 'problem',
     };
     return mapping[name] || name.toLowerCase().replace(/\s+/g, '_');
   }
   ```

3. Make the bar div clickable:
   - Add cursor-pointer class
   - Add onClick={() => onStageClick?.(getStageKey(stage.name))}
   - Add hover effect: hover:opacity-80 transition
   - Add keyboard accessibility: role="button", tabIndex={0}, onKeyDown for Enter/Space

4. Ensure the bar remains visually consistent - the existing styling stays, just add interactivity.
  </action>
  <verify>tsc --noEmit passes, bars have click handlers</verify>
  <done>FunnelChart bars are clickable and call onStageClick with stage key</done>
</task>
