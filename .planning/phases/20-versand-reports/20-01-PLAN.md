  <action>
Create GET endpoint at /api/reports/versand following the analytics/route.ts pattern.

Query params:
- from: ISO date string (required)
- to: ISO date string (required)

Returns JSON with:
1. **deliveryMetrics**: Object with:
   - total: number (total shipped orders in range)
   - onTime: number (versandUpdatedAt <= liefertermin)
   - late: number (versandUpdatedAt > liefertermin)
   - onTimePercent: number (0-100)
   - avgDelayDays: number (average days late for late orders, 0 if none)

2. **plzDistribution**: Array of { plz: string, count: number } sorted by count desc, top 10 PLZ prefixes (first 2 digits of lieferPlz)

3. **shippingTimes**: Object with:
   - avgDaysToShip: number (average days from versandbereit to versendet)
   - count: number (orders with both timestamps)

Query only orders where versandStatus='versendet' and versandUpdatedAt is within date range.

Use Supabase REST API consistent with existing pattern. Handle missing liefertermin gracefully (exclude from on-time calculation). Group PLZ by first 2 digits for regional analysis.
  </action>
