<task type="auto">

  <files>src/app/api/dashboard/kpi-orders/route.ts</files>
  <action>
Create new API route at `/api/dashboard/kpi-orders`:

```typescript
GET /api/dashboard/kpi-orders?type=total|critical|overdue[&date=YYYY-MM-DD]
```

Implementation:
1. Parse and validate query params:
   - `type` (required): 'total' | 'critical' | 'overdue'
   - `date` (optional): ISO date string, defaults to today

2. Call appropriate query function based on type:
   - 'total' → getOpenOrders(date)
   - 'critical' → getCriticalOrders(date)
   - 'overdue' → getOverdueOrders(date)

3. Return JSON response:
```typescript
{
  type: string;
  orders: KPIOrderItem[];
  count: number;
  date: string; // ISO date used for calculation
}
```

4. Error handling:
   - 400 for missing/invalid type
   - 400 for invalid date format
   - 500 for query errors

Follow existing patterns from reports/pipeline/route.ts:
- export const dynamic = 'force-dynamic'
- parseISO + isValid for date validation
- Structured error responses with German messages
  </action>
